## 5. Conflict semantics

Lossless does not mean "accept every conflicting file version simultaneously".

It means:

1. preserve source ancestry;
2. identify semantic conflict;
3. select or construct the non-regressive content state explicitly;
4. merge the ancestry;
5. record why the resolution is non-lossy.

This rule was applied to two real conflicts.

The ARPL report was advanced to the newer source-tip state before ancestry merge.

The phase-memory runtime retained the stricter integration implementation while the original audit branch ancestry was merged through a dedicated resolution branch.

## 6. Residual-preserving analysis

The consolidated main contains a residual-analysis family including:

- residual-preserving spectroscopy;
- layered residual discovery;
- recursive residual decomposition;
- domain contracts/adapters.

The design principle is that "noise" is not automatically discarded merely because it is residual.

The system instead separates at least three questions:

```text
Is the residual reproducible?
Is it coupled to known nuisance structure?
Does it carry domain-relevant information?
```

A residual may be useful computationally without being physically fundamental.

Physical attribution remains a downstream evidence question.
